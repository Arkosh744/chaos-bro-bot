# Trickster Bot

Дерзкий друг-трикстер в Telegram. Не коуч, не терапевт, не AI-ассистент. Помогает жить в моменте через сарказм, абсурд и контролируемый хаос.

---

## Возможности

### Кнопки (основное меню)

| Кнопка | Что делает |
|--------|-----------|
| **👁 Очнись** | Grounding-техника из пула 30+ упражнений. Inline-кнопка "Ещё" подгружает следующую в то же сообщение |
| **🎲 Ебани куба** | Рандомное хаос-задание (47 заготовок + генерация через Claude, 50/50). "Другое" — новое задание |
| **🔮 Судьба** | Рандомное трикстерское предсказание через Claude |
| **🎱 Кинь кости** | Рандомайзер решений — задай вопрос, бот решит за тебя |
| **🫁 Дыши** | Дыхательный таймер: 3 раунда (вдох 4с, задержка 4с, выдох 4с). Анимация через редактирование сообщения |
| **➡️ Ещё** | Открыть дополнительное меню |

### Кнопки (дополнительное меню)

| Кнопка | Что делает |
|--------|-----------|
| **🔥 Зажарь** | Roast на основе профиля пользователя через Claude |
| **🧙 Мудрость** | Абсурдная псевдо-философская мудрость |
| **⭐ Гороскоп** | Антигороскоп дня — один на всех, без знаков зодиака |
| **📊 Настроение** | ASCII-график настроения за 7 дней |
| **🪞 Зеркало** | Режим копирования стиля (см. ниже) |
| **⬅️ Назад** | Вернуться в основное меню |

## Личность

### Альтер-эго

~1/7 шанс активации на 24 часа. 10 личностей:

| Альтер-эго | Стиль |
|------------|-------|
| Философ | Экзистенциальные вопросы, цитирует выдуманных мыслителей |
| Гопник | "Чётко", "базару нет", семки, район |
| Аристократ | "Позвольте заметить", монокль, чай |
| Пират | "Йо-хо-хо", ром, паруса |
| Бабка у подъезда | "Вот в наше время...", всё знает |
| Йода | Говорит задом наперёд, "хм, да..." |
| Бард | Все ответы стихами и рифмами |
| Шеф-повар | Метафоры из кулинарии |
| Программист | "Ты в бесконечном цикле", "segfault в отношениях" |
| Кот | "Мяу", лениво, капризно, с превосходством |

### Тематические дни

Бот меняет характер в зависимости от дня недели:

- **Пн** — максимально саркастичен и циничен
- **Вт** — деловой и резкий
- **Ср** — философствует, задаёт неожиданные вопросы
- **Чт** — предвкушает пятницу
- **Пт** — расслаблен, весёлый
- **Сб** — ленивый
- **Вс** — мудрый и немного грустный

### Настроение по времени суток

- **Утро** (6-12) — сонный, ворчливый, отвечает лениво
- **День** (12-18) — максимально дерзкий и энергичный
- **Вечер** (18-23) — спокойный, философский
- **Ночь** (23-6) — полусонный, мистический, говорит загадками

### Уровни отношений

Бот адаптирует тон общения по количеству сообщений:

| Ур. | Название | Сообщений | Стиль |
|-----|----------|-----------|-------|
| 1 | Незнакомец | 0+ | Формально дерзкий, держит дистанцию |
| 2 | Знакомый | 21+ | Подъёбывает по-свойски |
| 3 | Кореш | 51+ | Шутит жёстче, "обижается" |
| 4 | Бро | 151+ | Как с лучшим другом, без фильтров |
| 5 | Кабан | 301+ | Максимальная дерзость, инсайд-шутки |
| 6 | Легенда | 501+ | Иногда серьёзно, от души |

### Память и интеллект

- **История** — все сообщения в SQLite
- **Summary** — обновляется каждые 20 сообщений через Claude (ключевые темы, настроение, факты)
- **Контекст** — summary + последние 5 сообщений в каждом вызове Claude
- **Профиль** — автоматическое извлечение фактов (имя, город, работа, хобби, игры, еда...) из разговоров
- **Детектор паттернов** — замечает повторяющееся поведение, троллит
- **Contextual recall** — ~15% шанс вспомнить что-то из прошлых разговоров
- **Ежедневная ложь** — один раз в день бот подмешивает правдоподобную выдумку. `/truth` раскрывает

### Механики

| Механика | Описание |
|----------|----------|
| Режим сна | 23:00-09:00: без Claude, ответы из пула ("zzz...", "сплю отъебись") |
| Пасхалки | зуг-зуг, 42, кабан, gg, F, ку, кек, for the horde, эмоджи — мгновенные ответы |
| Обида | Молчишь >24ч — бот обижается при первом сообщении |
| Торг | 20% шанс: "Отвечу, но сначала сделай 5 приседаний" |
| Лут | Каждые 10 сообщений выпадает рандомный подарок |
| Streak rewards | Вехи на 3, 7, 14, 30, 100 дней подряд |
| Ачивки | 17 достижений (первое сообщение, сова, жаворонок, болтун, фотограф...) |

## Wellness

### Привычки (`/habit`)

```
/habit              — список привычек со статусом
/habit add пить воду — добавить привычку
/habit done 1       — отметить привычку выполненной
/habit delete 1     — удалить привычку
```

Streak по каждой привычке. Напоминания о невыполненных 3 раза в день (10:00, 14:00, 19:00).

### Сон (`/sleep`)

Анализирует паттерны сна на основе первого и последнего сообщения за день. Показывает:
- Время засыпания и пробуждения по дням
- Среднее время сна
- Emoji-индикаторы качества

### Дыхание (`🫁 Дыши`)

Анимированный дыхательный таймер: 3 раунда box breathing (вдох 4с, задержка 4с, выдох 4с) с прогресс-баром.

## Планировщик

| Событие | Расписание | Описание |
|---------|-----------|----------|
| Рандомные пинги | Каждые 2-6ч (в окне min_hour-max_hour) | 40% игровые цитаты, 30% grounding, 30% подъёбка с контекстом |
| Утренний ритуал | 9:00-9:59 | Mood-чек (1-10 inline), затем утренний пакет (комментарий + задание + мотивашка) |
| Вечерняя рефлексия | 21:00-21:59 | Inline-кнопки: "Что хорошего" / "Что бесило" / "Что завтра" |
| Недельный дайджест | Вс ~20:00 | Статистика + roast за неделю |
| Напоминания привычек | 10:00, 14:00, 19:00 | Невыполненные привычки |
| Предупреждение о сне | 2:30 ночи | Если не спишь 3+ ночи за неделю |
| Доставка капсул | Каждый час | Проверка и доставка капсул времени (работает даже при выкл. планировщике) |
| Доставка напоминаний | Каждую минуту | Проверка и доставка напоминаний (работает всегда) |
| Бэкап БД | 4:00 | Ежедневный бэкап SQLite, хранит последние 7 |

## Веб-панель администратора

Встроенная SPA с dark glassmorphism темой. Доступ: `http://localhost:PORT?token=AUTH_TOKEN`.

### Вкладки

| Вкладка | Содержимое |
|---------|-----------|
| **Dashboard** | Статистика (всего/сегодня/за неделю сообщений), heatmap активности по часам |
| **Users** | Список пользователей с количеством сообщений и последней активностью |
| **Profile** | Профиль пользователя (факты), контекст бота (summary). Редактирование фактов |
| **Achievements** | Все ачивки со статусом (разблокирована / нет) |
| **Messages** | История сообщений в стиле чата (пузыри). Отправка сообщений пользователю |
| **Prompts** | Все 22 системных промпта с редактором. Переопределение и сброс к дефолту |
| **Settings** | Переключатель планировщика, часы активности, кнопка "Отправить пинг", скачивание бэкапа |

## Групповой режим

Бот работает в группах:

- **Упоминание или ответ** — бот отвечает при @mention или reply на его сообщение
- **Рандомные вставки** — настраиваемый шанс (по умолчанию 10%) вставить комментарий в чужое сообщение
- **Контекст группы** — сохраняет историю группы отдельно от личных чатов
- **Без клавиатуры** — в группах reply-кнопки не показываются
- **`/trickster`** — представление бота в группе
- **`/anon текст`** — анонимные сообщения (удаляет оригинал)

Для подслушивания: отключить Group Privacy в @BotFather.

## Чат

- **Свободный текст** — трикстер отвечает через Claude с характером
- **Вопрос с `?`** — рандомайзер решений вместо обычного ответа
- **Голосовое сообщение** — транскрипция через Groq Whisper, затем ответ от Claude
- **Фото** — реакция на фото (с учётом подписи)

## Конфиг

Файлы: `config.local.yaml` (приоритет) или `config.yaml`. Поддерживает `$ENV_VAR` в значениях. Fallback: `TELEGRAM_TOKEN` из окружения.

```yaml
telegram:
  token: "YOUR_BOT_TOKEN"        # обязательно
  owner_id: 123456789             # ID владельца для планировщика

claude:
  model: "sonnet"                 # модель Claude (default: sonnet)
  timeout: 120s                   # таймаут вызова (default: 30s)

scheduler:
  enabled: true                   # включить планировщик (default: false)
  min_hour: 9                     # начало окна пингов (default: 9)
  max_hour: 22                    # конец окна пингов (default: 22)

storage:
  db_path: "trickster.db"        # путь к SQLite (default: trickster.db)

groq:
  api_key: "YOUR_GROQ_KEY"       # для голосовых сообщений (опционально)

web:
  enabled: true                   # включить веб-панель (default: false)
  port: 8080                      # порт (default: 8080)
  auth_token: ""                  # токен авторизации (пустой = авто-генерация)

group:
  interject_chance: 10            # шанс рандомной вставки в группе, % (default: 10)
```

### Полный справочник секций

| Секция | Поле | Тип | Default | Описание |
|--------|------|-----|---------|----------|
| `telegram` | `token` | string | - | Telegram Bot Token (обязательно) |
| `telegram` | `owner_id` | int64 | 0 | ID владельца для утренних/вечерних чеков и дайджеста |
| `claude` | `model` | string | sonnet | Модель Claude |
| `claude` | `timeout` | duration | 30s | Таймаут запроса к Claude |
| `scheduler` | `enabled` | bool | false | Включить планировщик |
| `scheduler` | `min_hour` | int | 9 | Начало окна пингов (час) |
| `scheduler` | `max_hour` | int | 22 | Конец окна пингов (час) |
| `storage` | `db_path` | string | trickster.db | Путь к SQLite файлу |
| `groq` | `api_key` | string | - | Groq API ключ для Whisper |
| `web` | `enabled` | bool | false | Включить веб-панель |
| `web` | `port` | int | 8080 | Порт веб-панели |
| `web` | `auth_token` | string | (random) | Токен авторизации |
| `group` | `interject_chance` | int | 10 | Шанс рандомной вставки в группе (0-100) |

## Архитектура

```
Сообщение/голос → [Groq Whisper] → SQLite → summary + last 5 + profile → claude → ответ → SQLite
                                                                                    ↓
                                              каждые ~20 сообщений → обновляет summary
                                              каждое обновление → извлекает факты профиля
                                              детектор паттернов → roast если надо
```
